# SYCOM Academy Cybersecurity Scholarship 2026/27

## Passive OSINT Investigation

**Investigation date:** 17 October 2026  
**Classification:** Unverified — further verification required  
**Method:** Passive Open-Source Intelligence (OSINT)

## Objective

Assess the publicly observable technical characteristics,
organisational transparency and applicant-data considerations
associated with the advertised Sycom Academy Cybersecurity
Talent Pipeline Scholarship 2026/27.

## Scope

- Public scholarship advertisement and application page.
- DNS and hosting infrastructure.
- TLS certificate information.
- Frontend JavaScript and application architecture.
- Application questionnaire and data collection.
- Client-side file-upload implementation.
- Anti-spam honeypot implementation.
- Public Terms and Conditions and privacy disclosures.

## Principal findings

1. Application hosted on Microsoft Azure.
2. Frontend built with Next.js.
3. Clerk authentication-related components identified.
4. Application and API hostnames contain development-related naming.
5. Application collects personal, educational and financial information.
6. File-upload implementation includes a 10 MiB client-side limit
   and token-based references.
7. A hidden Website field consistent with an anti-spam honeypot
   was identified.
8. Generic CRM description found in scholarship-page metadata.
9. Available Terms and Conditions did not establish comprehensive
   scholarship-specific applicant protections.

## Limitations

No application was submitted. No credentials were entered.
No authentication bypass, exploitation, intrusive scanning or
unauthorised testing was conducted.

Backend security, organisational registration, scholarship funding,
data retention and actual privacy practices were not independently
verified.

## Conclusion

The investigation found evidence of a technically developed
application platform but insufficient independent evidence to
establish the scholarship's legitimacy, funding commitments and
applicant-data safeguards.

**Final classification: UNVERIFIED — FURTHER DOCUMENTARY
VERIFICATION REQUIRED.**

## Ethical statement

This investigation used passive examination of publicly accessible
information and locally collected website materials.

Findings are limited to the evidence available at the time of
investigation. No allegation of fraud or malicious activity is made.
